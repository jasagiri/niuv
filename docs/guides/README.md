## Tools and Scripts

### Enhanced Tools
The `tools/enhanced/` directory contains:
- `niuv_coverage_integration.nim` - TestKit coverage integration
- `benchmark_niuv_enhanced.nim` - Performance benchmarking tools
- `install-niuv-enhanced.sh` - Installation script
- Shell completion files for Bash, Zsh, and Fish

### Scripts
The `scripts/` directory contains:
- `niuv-coverage.sh` - Coverage execution script
- `niuv-benchmark.sh` - Benchmarking script
- `setup-niuv-dev.sh` - Development setup
- `setup-niuv-release.sh` - Release setup
