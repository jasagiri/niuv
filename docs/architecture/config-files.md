# Configuration Files Overview

This document explains the purpose of each configuration file in the niuv project root.

## Build Configuration

### `nim.cfg`
- **Purpose**: Minimal Nim compiler configuration
- **Content**: Basic nimble path setup
- **Generated by**: Configuration consolidation system

### `config.nims`
- **Purpose**: Dynamic build configuration
- **Content**: Profile-based compiler settings (debug, release, test, benchmark)
- **Generated by**: Configuration consolidation system

### `nimble.cfg`
- **Purpose**: Nimble-specific configuration
- **Content**: Binary output directory
- **Size**: Minimal (2 lines)

## Project Configuration

### `niuv.toml`
- **Purpose**: niuv-specific configuration
- **Content**: 
  - Build settings
  - Test configuration
  - Coverage thresholds
  - VCS preferences (Git/Jujutsu)
  - Delegation settings
- **User-editable**: Yes

### `nimtestkit.toml`
- **Purpose**: nim-testkit integration configuration
- **Content**:
  - Test discovery patterns
  - Coverage settings
  - Reporting preferences
- **Generated by**: Configuration consolidation system
- **User-editable**: Yes (but regenerated on config updates)

## Version Control

### `.gitignore`
- **Purpose**: Git ignore patterns
- **Content**: Build artifacts, temporary files, OS-specific files

## Documentation

### `README.md`
- **Purpose**: Main project documentation
- **Content**: Installation, usage, features

### `CHANGELOG.md`
- **Purpose**: Release history
- **Content**: Version changes, new features, fixes

### `CONTRIBUTING.md`
- **Purpose**: Contribution guidelines
- **Content**: Development setup, coding standards, PR process

### `LICENSE`
- **Purpose**: Legal license (MIT)
- **Content**: Copyright and permission notice

### `TODO.md`
- **Purpose**: Development roadmap
- **Content**: Planned features, known issues

### `CLAUDE.md`
- **Purpose**: AI assistant guidance
- **Content**: Project-specific instructions for Claude

## Build System

### `niuv.nimble`
- **Purpose**: Package definition and tasks
- **Content**: Dependencies, build tasks, metadata
- **Required**: Yes (Nimble package file)

### `Makefile`
- **Purpose**: Alternative build interface
- **Content**: Common commands for non-Nimble users

## Summary

The configuration has been minimized to essential files only:
- 3 Nim config files (nim.cfg, config.nims, nimble.cfg)
- 2 TOML config files (niuv.toml, nimtestkit.toml)
- Standard project files (README, LICENSE, etc.)

All configuration files serve a specific purpose with no redundancy.
